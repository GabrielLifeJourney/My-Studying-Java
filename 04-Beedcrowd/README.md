# Beecrowd - Créditos e Fontes de Estudo

![Beecrowd](Assets/IMG/beecrowd-cover.png)

## 1. Sobre a fonte

O **beecrowd** é uma plataforma de programação competitiva e avaliação automática de código. Seu ambiente reúne desafios de programação, atividades de prática e competições.

A plataforma organiza os problemas em diferentes categorias, incluindo Beginner (Iniciante), destinada a quem está começando a programar.

Utilizar o beecrowd como plataforma complementar de prática, resolvendo desafios de programação para desenvolver o raciocínio lógico e a capacidade de interpretar problemas e construir soluções.

Neste repositório, serão registradas as soluções desenvolvidas durante os estudos de Java. O conteúdo documentado será atualizado conforme os exercícios forem efetivamente realizados.
